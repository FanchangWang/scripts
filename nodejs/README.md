## 共性说明

- 均为 Node.js 原生 ESM，无第三方运行时依赖。
- 常用脚本以各项目 `package.json` 中的 `scripts` 为准：`npm start` 起本地服务，`npm test` 跑测试，`npm run build` 打包静态产物。
