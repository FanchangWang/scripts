Maye Nano 自动主题插件（Auto Theme）
================================================

当前版本号见插件设置窗口右下角；源码中定义在 src\p_AutoTheme.cpp 的 PLUGIN_VERSION。

功能
------------------------------------------------
- 跟随 Windows 浅色 / 深色模式自动切换 Maye Nano 的主题。
- 直接调用软件自身的主题切换函数：不重启软件，不会重新注册呼出窗口的热键。
- 打开软件「设置」窗口时会自动弹出本插件的设置窗口；软件设置关闭时自动隐藏。
  也可随时通过 设置 → 插件 → AutoTheme → 右侧「···」→ 选项 打开。
- 首次安装后第一次启动会自动弹出一次设置窗口；之后仅在主题文件丢失或
  打开软件设置时弹出。
- 插件设置窗口支持高 DPI，位置跟随软件窗口，置顶状态跟随软件 cfg.json
  中的 IsTopMost 设置；窗口自动跟随 Windows 浅色 / 深色模式换肤。
- 插件设置窗口打开期间暂停自动切换主题：可点下拉右侧的「预览主题」临时
  切换并查看效果；再次点击变为「取消预览」，点「取消预览」或关闭窗口后
  自动恢复按系统模式切换。两个预览按钮互斥，同时只能预览一个。在 7.1
  及以上版本，预览时还会自动打开软件设置窗口，便于在主窗口隐藏时查看效果。
- 7.1 及以上使用作者提供的官方 API 加载主题文件，不再依赖逆向函数地址；
  旧版本继续使用内置函数表，一份插件兼容多个版本。
- 窗口右下角显示插件自身版本号，点击「保存」提示确认后窗口自动关闭。

内置支持的版本
------------------------------------------------
- 7.1.0.261127（使用官方 LoadTheme API）
- 7.0.1.261107
- 6.2.0.260501
- 6.1.0.260422
- 6.0.0.260417

其他版本会尝试自动定位软件内部的主题函数；定位失败时功能静默，并在
插件设置窗口显示版本不支持提示，不会导致软件崩溃。

安装
------------------------------------------------
1. 完全退出 Maye Nano（包括托盘图标）。
2. 将压缩包内的三个文件复制到：

   <Maye Nano 安装目录>\plugin\mn.cc.arae.autotheme\

   目录不存在就新建。文件内容：
   - mn.cc.arae.autotheme.dll
   - autotheme.ini
   - 使用说明.txt
3. 编辑 <Maye Nano 安装目录>\cfg.json，在 plugin 数组中加入插件 ID：

   "plugin": ["mn.cc.arae.autotheme"]

   如果 plugin 数组中已有其他插件，用英文逗号分隔追加即可。
4. 启动 Maye Nano。首次启动会弹出插件设置窗口，确认主题后点击「保存」。

配置（autotheme.ini）
------------------------------------------------
[AutoTheme]
Enable=1                1=启用自动切换；0=关闭
Light=                  系统浅色时使用的主题文件名；留空 = 默认主题
Dark=Black-1.json       系统深色时使用的主题文件名；留空 = 默认主题
OpenWithSettings=1      1=打开软件设置窗口时自动弹出插件设置窗口；0=不弹
DebugLog=0              1=写 autotheme.log 便于排查；平时保持 0

主题文件名填写 theme 目录下的文件名（含 .json），如 Black-1.json。
插件设置窗口的下拉框会自动列出 theme 目录中所有 *.json 文件。

常见问题
------------------------------------------------
- 没有自动切换？
  确认 Enable=1、主题文件确实存在；打开插件设置窗口查看顶部版本匹配结果。
- 提示主题文件丢失？
  在插件设置窗口的下拉框里重新选择主题，点击「保存」。
- 不想每次打开软件设置都弹窗？
  把 OpenWithSettings 改成 0，或在插件设置窗口取消对应勾选。
- 想临时看看某个主题的实际效果？
  打开插件设置窗口，点对应下拉右侧的「预览主题」；看完点「取消预览」
  或直接关闭窗口，即恢复自动切换。
- 预览时系统深浅色变了会怎样？
  插件窗口打开期间暂停自动切换，预览不会被系统模式变化覆盖；关闭窗口后
  按当前系统模式恢复对应主题。
- 预览时为什么软件设置窗口也打开了？
  7.1 及以上会在预览时调用软件 API 主动打开设置窗口，这样即使主程序启动时
  隐藏了窗口，也能看到主题效果；旧版本没有这个 API，不会打开。

卸载
------------------------------------------------
删除 plugin\mn.cc.arae.autotheme 目录，并从 cfg.json 的 plugin 数组中
移除 "mn.cc.arae.autotheme"。
